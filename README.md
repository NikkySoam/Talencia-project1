# Talentra Database Project

## Prerequisites

- **Operating System**: Windows 10+ (PowerShell 5+ recommended)
- **PostgreSQL**: version 15.x (compatible with `pg_dump`, `psql`, `pgbench`)
- **Python**: 3.11+ (for synthetic data generator and test scripts)
- **pgTap**: installed in the target database (`CREATE EXTENSION pgtap;`).
- **Git**: for repository checkout.

## Clean Setup Instructions

1. Clone the repository (or copy the workspace) to a clean directory.
2. Create a new PostgreSQL database for development:
   ```powershell
   createdb talentra_dev
   psql -d talentra_dev -c "CREATE EXTENSION IF NOT EXISTS btree_gist;"
   psql -d talentra_dev -c "CREATE EXTENSION IF NOT EXISTS pgtap;"
   ```
3. Apply all migrations **in order**:
   ```powershell
   foreach ($file in Get-ChildItem -Path .\sql\migrations\V*.sql | Sort-Object Name) {
       psql -d talentra_dev -f $file.FullName
   }
   ```
4. Run the schema validation tests:
   ```powershell
   psql -d talentra_dev -f .\tests\schema_constraints.sql
   psql -d talentra_dev -f .\tests\transaction_rules.sql
   ```
5. (Optional) Generate synthetic data:
   ```powershell
   python .\scripts\generate_synthetic_data.py --seed 12345 --profiles 1000 --jobs 100 --applications 5000
   .\scripts\load_benchmark_data.sh
   ```
6. Execute benchmark queries:
   ```powershell
   psql -d talentra_dev -f .\benchmark\queries.sql > benchmark\results\raw_output.txt
   ```
7. Review the generated documentation in the `docs/` folder.

## Notes
- No secrets, passwords or API keys are stored in the repository.
- All identifiers are surrogate `BIGSERIAL` primary keys named `id`.
- All timestamps are stored as `TIMESTAMPTZ` in UTC.
- The synthetic data generator is deterministic given the same seed.

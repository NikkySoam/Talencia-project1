# Talentra — Database Provider Decision

**Selected database:** PostgreSQL

## Reason for selection

Our team has selected PostgreSQL for the Talentra Database Design Hackathon.

PostgreSQL supports relational data modelling, primary and foreign keys, constraints, transactional operations, indexing, and analytical queries. These capabilities are relevant to Talentra's requirements for candidate profiles, job applications, payments, access control, and performance measurement.

## Development environment

- Database engine: PostgreSQL
- Database administration: pgAdmin 4
- SQL editor: Visual Studio Code or pgAdmin Query Tool
- ER diagram tool: draw.io
- Version control: Git and GitHub
- Synthetic data generation: Python

## Decision

The team will use PostgreSQL as the database engine for the project. The schema, integrity rules, query performance, and backup/restore procedures will be validated against the hackathon requirements.

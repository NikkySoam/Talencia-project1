# Talentra — Module Assignment

## Common Foundation: Whole Team

| Work area | Ownership |
|---|---|
| Master Data | All team members |
| Profile | All team members |
| Jobs and Applications | All team members |
| Common naming standards and key conventions | All team members |
| Review and approval of the core ER diagrams | All team members |

## Individual Module Ownership

| Team member | Primary module responsibilities |
|---|---|
| Member A | Administration; Licences, Seats, Devices and Sessions |
| Member B | Organisation and Account; Sourcing and Consultant Requests |
| Member C | Gig Marketplace; Subscriptions, Wallet, Payments and Download History |
| All members | Notifications, Analytics, shared integration, testing and final review |

The individual assignments for the later phases are a proposed allocation for our three-person team. We will confirm ownership of the remaining modules together.

**Working agreement:** Each member must document their entities, relationships, columns, keys, constraints, and security requirements. All modules must integrate into one PostgreSQL database.
